MS Beatuty Capsule 1.1.0 绿色便携版

一、运行
将整个 ZIP 解压到当前用户可写的固定文件夹，然后运行 MSBeatutyCapsule.exe。
无需安装、管理员权限或后台服务；需要 Windows 11 x64 和 .NET Framework 4.8。
请保留 vendor 文件夹。运行前请退出旧安装版和其他便携副本。
本版仅有正式程序，不附带沙箱预览程序。

二、真正开机自启
首次运行正式程序时，默认登记当前用户登录后的开机自启；不需要再勾选。
它在当前用户的 Windows 启动文件夹中创建“MS Beatuty Capsule Portable.lnk”，
目标为当前文件夹的 MSBeatutyCapsule.exe --background，工作目录也设为便携目录。
创建后会读回核验；只有核验成功才清理同一路径旧版的 Run 注册值。
可以按 Win+R 输入 shell:startup，查看这个快捷方式。
以后登录时按 Data\Config\configuration.xml 恢复胶囊、位置、任务栏模式和自启选择。
托盘菜单可以取消或重新勾选“开机自动启动”，选择也会保存在配置中。
请勿只移动 EXE；移动整个文件夹后在新位置运行一次，程序会更新自启路径。
Windows 的任务管理器或组织策略可能另行禁用启动项，无法仅凭程序内设置保证系统实际执行。
托盘“检查/修复开机自启…”可以重新登记，并显示实际目标和配置目录。
Data\Logs\startup.log 记录每次进入程序、首个胶囊绘制耗时、重复实例退出、登记结果、初始化失败和桌面就绪。
本版先绘制胶囊，再检查自启登记和加载托盘图标。Windows 可能延迟执行启动文件夹项目，无法保证登录后立即运行。
登录早期桌面尚未就绪时，每半秒重试定位，最长 60 秒；一旦成功就停止重试。
升级请退出旧程序，把新 EXE 覆盖到原文件夹，保留 Data 与 vendor，再运行一次新版完成登记。

三、桌面胶囊
鼠标悬停在桌面胶囊上 0.5 秒自动展开，单击也可展开；双击条目用 Windows 默认程序打开目标。
可拖入照片、文档、音视频、压缩包、程序、.lnk/.url、无扩展名文件和文件夹。
单个文件不超过 5 MiB（5×1024×1024 字节）会复制到 Data\Capsules；超过 5 MiB 的文件和文件夹只保存原路径引用。
小文件和快捷方式复制后，即使删除桌面上的原件，胶囊内副本仍在；删除胶囊条目不会删除原件。
大文件或文件夹的原路径移动、删除或外置盘断开后，条目仍显示，但打开时会提示路径不可用。
旧版保存为引用的现存小文件会在第一个胶囊显示后逐项复制到胶囊；原文件已丢失的旧引用不会自动恢复。
鼠标位于覆盖桌面的其他窗口时，不会触发胶囊展开。
新建和拖动后会读取桌面图标格距，胶囊首行与图标首行对齐，可放在图标已有的格子；读取失败时回退到固定网格。
桌面活动时每约 2 秒检查一次图标格距与位置；鼠标滚轮调整桌面图标大小后会按新格距重新吸附。
新胶囊默认位置会参考图标分布：图标稀疏放中央；密集且偏左放右侧中间；密集且偏上放下方中间。
胶囊位于桌面图标上方，重叠时仍可见和拖动；如遮住原图标，可将胶囊拖到别处。
重新登录后从配置恢复位置；实际 Shell 网格和多屏效果仍需在你的桌面验证。
展开面板随快捷方式数量增减，不显示滚动条；多到屏幕放不下时用底部翻页按钮。
展开面板改用独立的半透明壁纸毛玻璃：读取当前静态桌面壁纸，按面板实际屏幕位置取样并模糊，
再以约 82% 不透明度合成背景；文字和图标本身保持清晰。它不依赖旧版的系统 Acrylic 调用。
支持多屏、不同缩放比例，以及填充、适应、拉伸、居中、平铺、跨屏壁纸位置。
读取和模糊在后台进行，面板改变大小或位置时重新对齐。不会截取屏幕、保存桌面截图或修改壁纸。
无法读取壁纸时保留半透明深色罩层，不再回退成近乎不透明的黑底。
这是针对桌面胶囊的壁纸毛玻璃，不会实时模糊背后的其他应用或视频/动态壁纸；每次展开重新读取壁纸设置。
程序及托盘图标改为戴墨镜的胶囊；桌面胶囊图案保持原样。
桌面胶囊保持在桌面层之上；点击右下角“显示桌面”时，程序还会在短时间内恢复被系统最小化或隐藏的胶囊。
右键胶囊或托盘选择“更名或删除胶囊…”，在列表中点名称更名，点“删除”删除。
管理列表和弹出的“胶囊更名”窗口都可替换/还原该胶囊的桌面图标。支持 PNG、JPG/JPEG、BMP、ICO；
建议 256×256 正方形，最长边不超过 1024 像素，文件不超过 2 MiB。选取后确认才会保存。
图标缩小保存在 Data\Icons，原图片不受影响。默认胶囊图提供 130 种颜色，在每个胶囊的“换色/透明度”中选择，并可调图标透明度 0–100%；默认 100% 不透明，名称仍保持可见。
上传自定义图后换色暂不可用；先点“还原胶囊图”，再调整颜色和透明度。外观选择会保存在 Data 配置中。
胶囊只放在桌面；本版不会添加新的任务栏固定入口。
原文件、文件夹、快捷方式和目标应用不会因为删除胶囊条目而被删除；胶囊内的小文件副本会被移除。

四、任务栏外观
托盘菜单提供“正常”“毛玻璃”“全透明”。
“毛玻璃”参考 TranslucentTB 2026.2，使用 ExplorerTAP 的 SetTaskbarBlur。
“全透明”使用透明 SolidColorBrush；“正常”恢复系统默认效果。
任务栏服务在 Explorer 初始化时可能尚未准备好，程序会短时重试；
调用记录在 Data\Logs\taskbar.log。日志证明请求已发送，不等于视觉效果已验证。
如果另一份 TranslucentTB 正在运行，请先退出它，以免两套外观互相覆盖。

五、数据与退出
配置、备份、自定义图标、新版小文件副本、旧版快捷方式副本和效果组件缓存都在程序旁的 Data 文件夹。
迁移时保留整个文件夹；程序不主动读取旧安装版的注册表配置。
退出：托盘图标右键→退出。
删除：托盘右键→“清理自启并退出”，确认程序退出后，按需备份 Data，再删除便携文件夹。普通“退出”会保留自启选择。
“清理自启并退出”只清理指向当前便携副本的启动快捷方式；清理或保存失败时会提示并保持程序运行。
如果已经删除程序但启动快捷方式仍在，按 Win+R 输入 shell:startup，手动删除 MS Beatuty Capsule Portable.lnk；不要动其他程序的快捷方式。
Explorer 可能在注销前仍占用 Data\Runtime 中的 DLL；遇到占用时请注销后再移动或删除。

六、终极整理模式（可选）
右键任务栏通知区的胶囊图标→“终极整理模式…”。此功能默认不开，首次运行和每次开机均不会自行执行。
程序先只读取当前用户桌面并弹出确认框；选择“否”不创建文件夹、不移动文件、不增加胶囊。
选择“是”后，在当前用户桌面新建“胶囊整理”，把桌面顶层可见的普通文件与快捷方式移动进去；
已有文件夹、隐藏/系统文件、公共桌面项目不移动。如果“胶囊整理”已存在，直接停止，避免覆盖。
移动中途失败会按逆序将已移动的文件退回桌面；若极少数文件未能回退，会提示并保留在“胶囊整理”中供手动处理。
然后尝试在资源管理器打开该文件夹，把窗口调整到所在屏幕左半边，并在右半边中央一带生成 5 个随机颜色胶囊。
这里使用窗口大小与位置调整，不创建 Windows Snap 分组；部分 Explorer 版本可能无法自动定位，可手动调整。
请先确认当前桌面是否有正在同步或使用中的文件；整理完成后可按需要把文件从“胶囊整理”移回桌面。

七、验证边界
本版通过 302 项无界面测试，其中终极整理模式在隔离临时目录验证了确认“否”、正常移动、冲突保护和中途失败回退；
资源管理器左半屏布局只验证几何计算，未对用户实际桌面、Explorer 窗口或 Windows Snap 做实机操作。
按照你的要求，开发过程没有启动正式程序、写入你电脑的真实自启或修改真实任务栏。
离屏图像检查确认新背景保留透明通道并能模糊壁纸，不能替代你电脑上的实际窗口验收。
真实登录后自启、显示桌面的出现速度、悬停命中和任务栏视觉效果尚待实际使用验证；不能保证没有 bug。
正常使用无需下载源码。完整对应源码及第三方源码见同一 GitHub Release 中单独提供的 Source.zip，便携包内不再嵌套源码包。GPL-3.0。
