M-Capsule 1.2.0 · Windows 11 x64 绿色便携版

【首次运行】将完整 ZIP 解压到当前用户可写的固定文件夹，运行 M-Capsule.exe。保留 M-Capsule.exe.config、vendor 和运行后生成的整个 Data。需要 .NET Framework 4.8；无需安装、管理员权限或单独下载源码。请勿同时运行旧版。

【从旧版升级】本版改了 EXE 文件名，v1.1.0 或更早版本不能只替换 EXE。先从托盘退出旧版并备份整个 Data，再把本版完整 ZIP 解压到旧便携目录，不删除 Data。运行 M-Capsule.exe，检查原有胶囊与配置。新版会登记并核验 M-Capsule.lnk，然后清理仅指向同目录旧版 EXE 的启动项。确认正常后，可手动删旧 MSBeatutyCapsule.exe 和相应 .config。移动位置时带上整个 Data，在新位置运行一次以更新自启目标。

【桌面胶囊】在胶囊上悬停约 0.5 秒展开；双击条目交给 Windows 默认程序。拖入文件会复制到 Data\Capsules，不限制文件大小；源文件之后被删除，副本仍在。文件夹只保存路径引用。旧版遗留的小文件引用会逐项迁移；已丢失的旧路径仍需手动恢复。拖出条目到桌面或资源管理器，目标接受后胶囊会移除该条目，文件副本进入回收站；旧版引用只从胶囊移除。拖入是复制，拖出是从胶囊移走。大文件复制可能暂时占用界面，请预留磁盘空间。

【胶囊管理】右键通知区图标，首选“◆ 胶囊管理 · Capsule Manager”。点击胶囊名称更名。复选多个胶囊后可批量删除、统一上传图片、统一设置颜色和透明度。自定义图片胶囊不能换色，需先还原默认图。右上角“⚙ 文/A”依次切换中文、英语、日语，选择保存在 Data。默认图有 130 种颜色，图标透明度可选 0–100%，默认 100% 不透明。自定义图支持 PNG/JPEG/BMP/ICO，最大 2 MiB、最长边 1024 像素，建议 256×256 正方形，上传确认后保存。

【终极整理模式】默认关闭，只有在托盘明确点击并确认后运行。选择“否”不改变任何文件。选择“是”后，把当前用户桌面顶层可见的普通文件和快捷方式移入桌面的“胶囊整理”文件夹，打开并尝试排到左半屏，右半屏每次新建 5 个随机色胶囊。已有“胶囊整理”时复用；同名文件加序号，绝不覆盖。已有文件夹、隐藏/系统项目及公共桌面项目不会移动。移动中途失败会尝试回退；进程被强制终止或同步软件同时更改文件时，手动核查桌面和整理文件夹。左半屏只是窗口位置调整，不创建 Windows Snap 分组。

【开机自启和退出】默认在当前 Windows 用户登录后自启。程序在当前用户启动文件夹创建 M-Capsule.lnk，指向本目录 M-Capsule.exe --background，并读回核验；配置、胶囊位置与自启选择存在 Data。托盘可开关和检查/修复。Windows 设置、策略或启动项目排队仍可能影响实际执行速度。停用前选择“清理自启并退出”；若软件已删除，可按 Win+R 输入 shell:startup，仅删除本程序的 M-Capsule.lnk 或旧版 MS Beatuty Capsule Portable.lnk。普通退出保留自启设置。日志见 Data\Logs\startup.log 和 taskbar.log，公开前检查个人路径。

【外观和范围】展开面板使用静态壁纸取样并模糊，不截取其他窗口或动态壁纸；任务栏正常、毛玻璃、全透明依赖 Windows Explorer 环境。目标系统为 Windows 11 x64；Windows 10 和 ARM64 未系统验证，macOS/Linux 不提供。开发仅运行隔离无界面测试，未控制真实桌面、任务栏或启动文件夹；实际拖放和显示仍需使用反馈。项目按 GPL-3.0 发布，源码 ZIP 单独提供，普通运行不需要。

M-Capsule 1.2.0 · Portable for Windows 11 x64

[First run] Extract the complete ZIP into a fixed user-writable folder and run M-Capsule.exe. Keep M-Capsule.exe.config, vendor, and all of Data created at runtime. .NET Framework 4.8 is required. No installer, administrator rights, or separate source download is needed. Do not run the old version alongside it.

[Upgrade] The EXE has a new name, so users of v1.1.0 or earlier cannot upgrade by replacing only an EXE. Exit the old app and back up all of Data. Extract the full new ZIP into the same portable folder without deleting Data. Run M-Capsule.exe and check your capsules and preferences. The app registers and verifies M-Capsule.lnk, then retires old startup entries pointing to the former EXE in that same directory. After checking, you may manually remove MSBeatutyCapsule.exe and its matching .config. When relocating, move the entire Data directory and run the app once in the new location.

[Desktop capsules] Hover for about 0.5 seconds to expand; double-click an entry to open it with Windows. Imported files of any size are copied into Data\Capsules and survive removal of the original. Folders remain path references. Existing small-file references from older versions migrate gradually; missing source paths require manual recovery. Drag an entry to Explorer or the desktop: after a successful drop the capsule removes it and its stored copy goes to the Recycle Bin; old references are removed from the capsule only. Dragging in copies; dragging out removes from the capsule. Allow disk space for large copies, which may briefly occupy the UI.

[Capsule Manager] Right-click the tray icon and select “◆ Capsule Manager.” Click a name to rename it. Select multiple capsules to batch-delete, apply one image, or set one color and opacity. Restore the default image before coloring a capsule with a custom image. “⚙ 文/A” cycles Chinese, English, and Japanese; the selection is saved in Data. Default artwork has 130 colors and 0–100% opacity, initially 100%. Custom images accept PNG/JPEG/BMP/ICO up to 2 MiB and 1024 pixels on the longest side; 256×256 square is recommended. Confirm the image before saving.

[Ultimate Organizing Mode] Off by default; it runs only after a tray-menu action and confirmation. Choosing No changes nothing. Choosing Yes moves ordinary, visible, top-level files and shortcuts on the current user's Desktop into its 胶囊整理 folder, opens the folder, attempts to place Explorer on the left, and creates five new random-color capsules on the right every time. An existing organizing folder is reused, and colliding filenames are numbered without overwriting. Existing folders, hidden/system items, and Public Desktop items stay put. A mid-operation failure attempts rollback; after a forced exit or concurrent sync changes, check both the Desktop and organizing folder. Left-half placement resizes/moves a window; it does not create a Windows Snap group.

[Startup and exit] Launch at the current user's sign-in is enabled by default. The app creates M-Capsule.lnk in that user's Startup folder, targeting this copy's M-Capsule.exe --background, and verifies it. Preferences and capsule positions live in Data. The tray can toggle and inspect/repair startup. Windows settings, policy, and Startup scheduling can still affect actual launch timing. Choose “Clean startup and exit” before removal. If the app is already gone, use Win+R → shell:startup and remove only its M-Capsule.lnk or old MS Beatuty Capsule Portable.lnk. Ordinary exit preserves the startup choice. Logs are in Data\Logs; inspect personal paths before sharing them.

[Appearance and scope] The panel samples and blurs a static wallpaper rather than capturing other windows or live wallpaper. Normal, blurred, and clear taskbar modes depend on Windows Explorer. Target system: Windows 11 x64; Windows 10 and ARM64 are unverified, and macOS/Linux builds are unavailable. Development used isolated headless tests only, without operating the real desktop, taskbar, or Startup folder. Actual drag/drop and visuals still need user feedback. GPL-3.0 source is supplied separately; it is not needed to run the app.
