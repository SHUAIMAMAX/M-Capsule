MS Beatuty Capsule 0.6.5 绿色便携版

一、运行
将整个 ZIP 解压到当前用户可写的固定文件夹，然后运行 MSBeatutyCapsule.exe。
无需安装、管理员权限或后台服务；需要 Windows 11 x64 和 .NET Framework 4.8。
请保留 vendor 文件夹。运行前请退出旧安装版和其他便携副本。
本版仅有正式程序，不附带沙箱预览程序。

二、真正开机自启
首次运行正式程序时，默认登记当前用户登录后的开机自启；不需要再勾选。
它在当前用户的 Windows 启动文件夹中创建“MS Beatuty Capsule Portable.lnk”，
目标为当前文件夹的 MSBeatutyCapsule.exe --background，工作目录也设为便携目录。
创建后会读回核验；只有核验成功才清理同一路径旧版的 Run 注册值。
可以按 Win+R 输入 shell:startup，查看这个快捷方式。
以后登录时按 Data\Config\configuration.xml 恢复胶囊、位置、任务栏模式和自启选择。
托盘菜单可以取消或重新勾选“开机自动启动”，选择也会保存在配置中。
请勿只移动 EXE；移动整个文件夹后在新位置运行一次，程序会更新自启路径。
Windows 的任务管理器或组织策略可能另行禁用启动项，无法仅凭程序内设置保证系统实际执行。
托盘“检查/修复开机自启…”可以重新登记，并显示实际目标和配置目录。
Data\Logs\startup.log 记录每次进入程序、重复实例退出、登记结果、初始化失败和桌面就绪。
登录早期桌面尚未就绪时，每半秒重试定位，最长 60 秒；一旦成功就停止重试。
升级请退出旧程序，把新 EXE 覆盖到原文件夹，保留 Data 与 vendor，再运行一次新版完成登记。

三、桌面胶囊
鼠标悬停在桌面胶囊上 0.5 秒自动展开，单击也可展开；双击快捷方式启动目标。可拖入 .lnk/.url 或用“＋”添加。
鼠标位于覆盖桌面的其他窗口时，不会触发胶囊展开。
新建和拖动后会吸附桌面网格；重新登录后从配置恢复。
展开面板随快捷方式数量增减，不显示滚动条；多到屏幕放不下时用底部翻页按钮。
展开面板改用独立的半透明壁纸毛玻璃：读取当前静态桌面壁纸，按面板实际屏幕位置取样并模糊，
再以约 82% 不透明度合成背景；文字和图标本身保持清晰。它不依赖旧版的系统 Acrylic 调用。
支持多屏、不同缩放比例，以及填充、适应、拉伸、居中、平铺、跨屏壁纸位置。
读取和模糊在后台进行，面板改变大小或位置时重新对齐。不会截取屏幕、保存桌面截图或修改壁纸。
无法读取壁纸时保留半透明深色罩层，不再回退成近乎不透明的黑底。
这是针对桌面胶囊的壁纸毛玻璃，不会实时模糊背后的其他应用或视频/动态壁纸；每次展开重新读取壁纸设置。
程序及托盘图标改为戴墨镜的胶囊；桌面胶囊图案保持原样。
桌面胶囊保持在桌面层之上；点击右下角“显示桌面”时，程序还会在短时间内恢复被系统最小化或隐藏的胶囊。
右键胶囊或托盘选择“更名或删除胶囊…”，在列表中点名称更名，点“删除”删除。
胶囊只放在桌面；本版不会添加新的任务栏固定入口。
原快捷方式和目标应用不会因为删除胶囊条目而被删除。

四、任务栏外观
托盘菜单提供“正常”“毛玻璃”“全透明”。
“毛玻璃”参考 TranslucentTB 2026.2，使用 ExplorerTAP 的 SetTaskbarBlur。
“全透明”使用透明 SolidColorBrush；“正常”恢复系统默认效果。
任务栏服务在 Explorer 初始化时可能尚未准备好，程序会短时重试；
调用记录在 Data\Logs\taskbar.log。日志证明请求已发送，不等于视觉效果已验证。
如果另一份 TranslucentTB 正在运行，请先退出它，以免两套外观互相覆盖。

五、数据与退出
配置、备份、快捷方式副本和效果组件缓存都在程序旁的 Data 文件夹。
迁移时保留整个文件夹；程序不主动读取旧安装版的注册表配置。
退出：托盘图标右键→退出。
删除：先在托盘取消开机自启，退出程序，备份 Data 后删除便携文件夹。
Explorer 可能在注销前仍占用 Data\Runtime 中的 DLL；遇到占用时请注销后再移动或删除。

六、验证边界
本版通过离线编译、配置和模拟存储测试、网格定位测试、自启快捷方式专项和壁纸背景像素测试。
按照你的要求，开发过程没有启动正式程序、写入你电脑的真实自启或修改真实任务栏。
离屏图像检查确认新背景保留透明通道并能模糊壁纸，不能替代你电脑上的实际窗口验收。
真实登录后自启、显示桌面的出现速度、悬停命中和任务栏视觉效果尚待实际使用验证；不能保证没有 bug。
