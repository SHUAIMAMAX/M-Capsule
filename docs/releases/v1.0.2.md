# v1.0.2 · 小文件与快捷方式保留副本

拖入单个文件时，**不超过 5 MiB（5×1024×1024 字节）**会复制到便携目录的 `Data/Capsules`，包括 `.lnk/.url` 快捷方式、照片和文档。删除桌面上的原快捷方式，胶囊内副本仍在。**超过 5 MiB** 的文件和所有文件夹只保存原路径引用；原路径失效时需要恢复路径或重新拖入。删除胶囊条目不会删除原文件。

升级时，旧版已保存为引用且原文件仍可访问的小文件，会在首个胶囊显示后逐项复制进胶囊；原文件已经丢失或无法读取的条目保持原引用。升级前建议备份整个 `Data` 文件夹。配置格式升级到 v4，旧版程序不能读取升级后的配置。

通过 284 项本地离线检查，包括 5 MiB 边界、原快捷方式删除后的副本、旧引用迁移、配置恢复和现有网格、自启、毛玻璃行为。未操作用户真实桌面、启动文件夹或任务栏；仍需 Windows 11 x64 实机使用反馈。本版继续使用 .NET Framework 4.8。

已有便携版：先从托盘退出，用 `MSBeatutyCapsule.exe` 覆盖原目录的 EXE，保留 `Data`、`vendor` 和 `.exe.config`，再运行一次。首次使用下载完整便携 ZIP。
