# v1.1.0 · 密集桌面可见胶囊与可选终极整理

胶囊现在保持在桌面图标上方，图标密集时不会因为重叠而消失。新胶囊按已读取的桌面图标分布放置：图标较少时放中央；图标密集且集中左侧时放右侧中间；集中上方时放下方中间。首次创建的胶囊也适用；已有胶囊位置不重置。

托盘新增手动触发的**终极整理模式**，默认关闭，启动时绝不自动执行。点击后先显示确认框；选“否”不做任何改动。选“是”才在当前用户桌面创建 `胶囊整理` 文件夹，移动桌面顶层可见的普通文件和快捷方式，随后打开文件夹并尝试将资源管理器窗口放到左半屏，在右半屏生成五个随机颜色的胶囊。已有文件夹、隐藏或系统文件、公共桌面项目不移动。同名整理文件夹已存在则停止，避免覆盖。中途移动失败会回退已移动文件；若 Explorer 自动排列失败，文件仍安全地留在整理文件夹，可手动排列窗口。

资源管理器左半屏效果通过设置窗口大小和位置实现，**不会创建 Windows Snap 分组**。Windows 版本、窗口标签页和缩放环境可能影响自动排列。

已通过 304 项本地无界面检查，其中 14 项在隔离临时目录与沙箱路径验证整理操作，6 项新增网格与布局测试。没有操作用户真实桌面、文件、任务栏或启动文件夹；实际 Explorer 窗口定位与多屏视觉效果仍需用户实机反馈。目标系统为 Windows 11 x64 / .NET Framework 4.8。

从 v1.0.2 升级：先退出旧版，用 `MSBeatutyCapsule.exe` 覆盖原目录的 EXE，保留 `Data`、`vendor` 和 `.exe.config`。初次使用下载完整便携 ZIP；后续版本请以相应发行说明为准，不能默认每次只替换 EXE。

下载：`MSBeatutyCapsule.exe`（仅升级）、`MS-Beatuty-Capsule-Portable-1.1.0.zip`（完整便携版）、`MS-Beatuty-Capsule-Portable-1.1.0-Source.zip`（单独的对应源码，正常使用无需下载）、`SHA256SUMS.txt`（校验）。便携 ZIP 内不再嵌套源码 ZIP。
