# M-Capsule v1.2.0 · 轻巧整理，随手带走

**给桌面吃点药，缓解你的桌面焦虑。** 完整便携 ZIP 不到 0.7 MB，比许多照片还小。继续保持免安装、本地保存、登录自启，以及简单、克制的设计。

这一版将产品、EXE、发布包及 GitHub 仓库统一更名为 **M-Capsule**。胶囊管理支持复选：批量删除、统一图片、统一颜色与透明度，右上角 **⚙ 文/A** 可切换中文、英语、日语；托盘首项为 **◆ 胶囊管理 · Capsule Manager**。新拖入的文件不论大小都复制到 `Data/Capsules`，从胶囊拖出后在目标接受时移走胶囊条目。文件夹和旧版仍未迁移的路径引用保留原路径语义。

终极整理模式现在每次成功运行都新建 5 个胶囊，即使之前的胶囊已全部删除。再次运行会复用已有 `胶囊整理` 文件夹；同名文件加序号，不覆盖旧文件。模式仍需托盘主动点击并确认，绝不随开机执行。移动失败时尝试回退；资源管理器左半屏为窗口位置调整，不是 Snap 分组。

**从 v1.1.0 或更早版本升级，必须使用完整便携 ZIP，不能只覆盖旧 EXE。** 先退出旧版并备份 `Data`，将新版完整 ZIP 解压到原便携目录且保留整个旧 `Data`，运行 `M-Capsule.exe` 核对配置。新版会先核验 `M-Capsule.lnk` 再移除属于同目录旧版的自启项。确认正常后，可手动删除旧 `MSBeatutyCapsule.exe` 及其 `.config`。初次使用也下载完整 ZIP；正常运行不需要源码 ZIP。

下载：`M-Capsule-Portable-1.2.0.zip`（完整便携版）、`M-Capsule.exe`（新版程序，旧版不能单文件升级）、`M-Capsule-Portable-1.2.0-Source.zip`（对应源码，使用时无需下载）、`SHA256SUMS.txt`（校验）。目标为 Windows 11 x64 / .NET Framework 4.8；Windows 10 和 ARM64 未系统验证。通过 316 项离线隔离检查；按使用者要求，没有操作真实桌面、自启或任务栏。资源管理器实际拖放、窗口显示及登录时序仍需真实使用反馈。无代码签名证书。

# M-Capsule v1.2.0 · Small, simple desktop organization

**Give your desktop a little medicine and ease the anxiety of desktop clutter.** The complete portable ZIP is under 0.7 MB, smaller than many photos. No installer, local data, launch at sign-in, and a deliberately simple design.

The product, EXE, release files, and GitHub repository are now named **M-Capsule**. Capsule Manager supports multiselection for batch deletion, one shared image, or shared color and opacity. **⚙ 文/A** cycles Chinese, English, and Japanese. The leading tray item is **◆ Capsule Manager**. Newly imported files of any size are copied into `Data/Capsules`; dragging an entry out removes it after an accepted drop. Folders and unmigrated legacy path references retain their path-reference behavior.

Ultimate Organizing Mode now creates five new capsules on every successful run, even after all previous capsules were deleted. Later runs reuse the existing `胶囊整理` folder; colliding filenames receive numbered suffixes instead of overwriting existing files. The mode still requires an explicit tray action and confirmation and never runs at startup. Failed moves attempt rollback. Left-half Explorer placement is window positioning, not a Windows Snap group.

**Users upgrading from v1.1.0 or earlier must use the complete portable ZIP, not just replace the old EXE.** Exit the old app and back up `Data`; extract the complete new ZIP into the original portable directory while preserving all of `Data`. Run `M-Capsule.exe` and check your settings. The app verifies `M-Capsule.lnk` before retiring old startup entries belonging to that same directory. After checking, you may manually remove the old `MSBeatutyCapsule.exe` and matching `.config`. First-time users also need the full ZIP; the separate source ZIP is not needed to run the app.

Assets: `M-Capsule-Portable-1.2.0.zip` (complete portable app), `M-Capsule.exe` (new executable; not a standalone upgrade from the old name), `M-Capsule-Portable-1.2.0-Source.zip` (matching source, optional for users), and `SHA256SUMS.txt` (checksums). Target: Windows 11 x64 / .NET Framework 4.8; Windows 10 and ARM64 are not systematically verified. The release passed 316 isolated offline checks. At the user's request, development did not operate their real desktop, Startup folder, or taskbar. Actual Explorer drag/drop, rendering, and sign-in timing still need real-use feedback. The binary is unsigned.
