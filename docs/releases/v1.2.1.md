# M-Capsule v1.2.1

桌面胶囊现在可以直接右键操作：**更名、改色、改透明度、删除**。四项分别打开只处理当前胶囊的小窗口，不必先进入胶囊管理。改色不会改变透明度；改透明度不会改变颜色，也可用于自定义图片。透明度 0% 为不透明、100% 为完全透明，名称保持可见。删除仍会先确认。

管理窗口右上角绿色 **+** 用于新建胶囊；底部下划线链接关闭开机自启而不退出程序。托盘右键菜单现在依次分为“胶囊管理 / 任务栏外观 / 终极整理模式”、“开机自动启动 / 检查修复自启”、“帮助 / 退出”，不再在托盘提供新建入口。终极整理生成的胶囊明确设为完全不透明，同时减轻默认矢量图的泛白高亮。

本版还包含：胶囊图案跟随桌面图标的小、中、大尺寸，默认图为程序内矢量路径；文件拖入复制、副本重新导入和终极整理的修复均保留。没有附带 2048×2048 位图，也没有把源码塞进便携 ZIP。

目标系统为 **Windows 11 x64 / .NET Framework 4.8**。完整便携包请保留 `M-Capsule.exe.config`、`vendor` 和运行后生成的整个 `Data`。若从旧名 `MSBeatutyCapsule.exe` 的版本升级，须解压完整 ZIP 到原便携目录并保留 `Data`；不能只替换旧 EXE。1.2.1 通过 348 项隔离检查；按使用者要求，本轮没有操作真实桌面，也没有运行会显示窗口的集成测试。使用者已完成初步试用；其他 Windows 设备上的界面效果尚未系统验证。

# M-Capsule v1.2.1

Desktop capsules now have four direct right-click commands: **Rename, Change color, Change transparency, and Delete**. Each opens a focused dialog for that capsule without entering Capsule Manager. Color and transparency change independently; transparency also works with custom images. 0% transparency is opaque and 100% is invisible, while the name remains visible. Deletion still asks for confirmation.

The green **+** at the top right of Capsule Manager creates a capsule. Its underlined footer link disables launch at sign-in without closing the app. The tray menu now has three groups: management/appearance/organizing, startup settings/repair, and help/exit. Capsule creation is no longer a tray action. Capsules created by Ultimate Organizing explicitly use full artwork opacity; the vector artwork has less pale shine so it looks more solid.

This version includes earlier improvements: artwork follows small, medium, and large desktop icon sizes; default artwork uses in-app vector paths. File-copy, safe reimport, and Ultimate Organizing fixes remain included. No 2048×2048 bitmap or source archive is placed in the portable ZIP.

Target: **Windows 11 x64 / .NET Framework 4.8**. Preserve `M-Capsule.exe.config`, `vendor`, and the complete `Data` directory. Upgrading from an older `MSBeatutyCapsule.exe` build requires the full ZIP in the original portable folder while retaining `Data`; replacing only the old EXE will not work. Version 1.2.1 passed 348 isolated checks. At the user's request, this round did not operate the real desktop or run window-opening integration tests. The user completed an initial hands-on test; display behavior on other Windows devices has not been systematically verified.
