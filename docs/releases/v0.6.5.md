# v0.6.5 · 轻量桌面胶囊便携版

一个由个人需求驱动、通过 Vibe Coding 方式开发的 Windows 小工具：把常用快捷方式收进几个桌面胶囊，鼠标悬停半秒展开，登录后按原配置恢复。

产品取向是轻量、简单、够用。维护重心放在桌面整理、快捷方式启动、开机自启与基础外观，克制增加复杂功能。

## 适用系统

Windows 11 x64（Intel / AMD 64 位），建议 22H2 及以上，依赖 .NET Framework 4.8。普通用户运行，无需管理员权限。Windows 10、Windows ARM64 和其他平台未提供验证。

## 基础功能

- 桌面胶囊分类、拖入快捷方式、双击打开。
- 悬停 0.5 秒展开，覆盖桌面的其他窗口不会触发展开。
- 网格对齐，集中更名与删除。
- 半透明壁纸毛玻璃展开面板，内容自适应。
- 默认开启当前用户登录自启，保存胶囊、位置和设置。
- 托盘提供少量基础管理和任务栏外观选项。

## 本版变化

展开面板改用逐像素半透明窗口与壁纸取样模糊，移除旧版近乎不透明的黑底回退。保留 v0.6.4 的自启快捷方式核验、启动日志与桌面就绪重试。

毛玻璃取样来自静态壁纸，不实时模糊其他应用或动态壁纸。任务栏效果依赖实际 Windows 环境。

## 下载哪个文件

- `MS-Beatuty-Capsule-Portable-0.6.5.zip`：首次使用下载这个，完整解压后运行 EXE。

- `MS-Beatuty-Capsule-Portable-0.6.5-Source.zip`：对应源码和第三方源码。
