# v0.6.6 · 文件引用、自定义图标与桌面网格

本版把桌面胶囊扩展为轻量入口：照片、文档、音视频、压缩包、程序、快捷方式和文件夹都能拖入。胶囊仅保存文件的绝对路径，不复制内容；删除条目不碰原文件。原路径失效时条目保留，并在打开时提示。

胶囊可读取 Windows 桌面图标的网格间距和占用位置，放置时尽量跟随同一网格、避开原图标；Shell 视图不可读取时回退旧网格。管理列表和“胶囊更名”窗口新增每个胶囊的图标替换、确认与还原。支持 PNG、JPG/JPEG、BMP、ICO，最长边不超过 1024 像素，文件不超过 2 MiB，建议 256×256 正方形。用户图标缩小保存在便携目录 `Data/Icons`，默认胶囊图提供 130 种颜色。

启动顺序调整为优先绘制胶囊，再检查自启登记、显示托盘和按需载入文件图标。`Data/Logs/startup.log` 会记录从程序入口到首个胶囊绘制的毫秒数。Windows 仍可能延迟启动文件夹中的程序，不能保证登录后固定几秒内显示。

已通过 258 项本地离线检查。桌面 Shell 网格读取及真实登录后的总等待时间，仍需在实际 Windows 桌面验证。未操作用户真实自启、桌面或任务栏。

升级：先退出旧版，用本页 EXE 覆盖原目录中的 `MSBeatutyCapsule.exe`，保留整个 `Data`、`vendor` 文件夹和 `.exe.config` 后运行。初次使用请下载完整便携 ZIP。新版配置使用 v3；升级前建议备份整个 `Data`，旧版程序无法识别新增的文件引用。

下载文件：`MSBeatutyCapsule.exe`（仅升级）、`MS-Beatuty-Capsule-Portable-0.6.6.zip`（首次使用）、`MS-Beatuty-Capsule-Portable-0.6.6-Source.zip`（对应源码）、`SHA256SUMS.txt`（校验）。
