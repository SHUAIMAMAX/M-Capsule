# v1.0.0 · 每个胶囊独立换色与停用清理

桌面胶囊管理列表和“胶囊更名”窗口现在都能为每个默认胶囊选择 130 种颜色之一，并设置图标透明度 0–100%。变更后立即更新桌面图标，下次启动仍按原设置显示；名称不受透明度影响。上传自定义图标的胶囊需先还原默认图，才能换色。

托盘右键新增“清理自启并退出”：清理指向当前便携副本的启动快捷方式，保存关闭自启的选择后退出。清理或保存失败时保留程序运行并提示；普通“退出”仍保留自启设置。删除便携文件夹前请先执行此操作并按需备份 `Data`。如果已经删除程序，可在 `shell:startup` 手动移除本程序的快捷方式。

已通过 264 项本地离线检查，覆盖旧版配置加载、颜色与透明度保存、自启快捷方式清理失败等情况。测试未写入真实 Windows 自启，也未操作用户桌面或任务栏；实际登录自启及 UI 视觉表现仍需在目标机器验收。EXE 未签名。

升级：先从托盘退出旧版，用本页 `MSBeatutyCapsule.exe` 覆盖原目录的 EXE，保留整个 `Data`、`vendor` 文件夹和 `.exe.config`，然后运行。初次使用请下载完整 ZIP。删除前使用“清理自启并退出”。
