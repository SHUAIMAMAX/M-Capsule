# v1.0.1 · 桌面图标网格与默认胶囊清晰度

胶囊现在按 Windows 桌面图标格子的起点吸附，不再额外居中或留出边距。它可以放在图标网格的首行，也可以与原图标占用同一格；两个胶囊仍会互相避让。重叠时原桌面图标优先显示和接收点击，胶囊暂时隐藏；移走原图标后会重新出现。

桌面活动时约每 2 秒读取一次图标格距和位置。用鼠标滚轮调整桌面图标大小后，胶囊会按新格距重新吸附；更新并非瞬时，Shell 视图不可读取时回退到固定网格。

修复前 10 种默认胶囊颜色被误当作透明 ARGB 的问题。现在默认图案的两半均为不透明颜色，新胶囊图标透明度仍默认 100%；用户选过的 0–100% 透明度设置保留。

已通过 271 项本地离线检查。测试没有改动用户真实桌面、自启或任务栏；鼠标滚轮缩放后的 Shell 回调、图标遮挡及多屏视觉效果仍需在目标 Windows 桌面实机验收。适用 Windows 11 x64 / .NET Framework 4.8。

升级：先退出旧版，用 `MSBeatutyCapsule.exe` 覆盖原目录的 EXE，保留 `Data`、`vendor` 和 `.exe.config`。初次使用下载完整便携 ZIP。
