## 已知边界

- **系统支持**：目标为 Windows 11 x64 / .NET Framework 4.8。Windows 10、ARM64 和定制桌面环境没有系统性验证。
- **毛玻璃**：使用静态壁纸取样模糊，并保留真实透明度；不实时采集或模糊其他窗口、视频、动态壁纸。壁纸读取失败时使用半透明罩层。
- **开机自启**：使用当前用户启动文件夹，Windows 设置或组织策略可以禁用启动项。目录改变后，需要在新位置运行以更新登记。
- **删除便携目录**：程序删除后无法自行运行并清理残留启动快捷方式；应先用托盘“清理自启并退出”，若已删除则在 `shell:startup` 中手动移除本程序快捷方式。该清理动作未在真实用户启动文件夹验收。
- **启动速度**：新版缩短进程进入到首个胶囊显示前的同步工作；`startup.log` 的 `first capsule rendered elapsed_ms` 不含 Windows 排队启动的时间。Windows 可推迟执行启动文件夹项目，无法保证登录后几秒内出现。没有操作真实桌面或重启作实机计时。
- **桌面网格**：读取系统 Shell 视图失败时会使用固定网格。桌面活动时约每 2 秒读取一次；图标缩放或移动后不会瞬间更新。新胶囊按已读取的图标分布选择位置；若读取尚未完成，先显示在中央。胶囊与图标重叠时保持可见并位于桌面层上方；真实 Shell 层级、缩放和多屏表现尚未在用户实际桌面验收。
- **终极整理模式**：只在托盘点击并确认后运行。仅移动当前用户桌面顶层可见的文件和快捷方式；已有文件夹、隐藏/系统项目和公共桌面项目保留原位。同名目标文件夹存在时停止。移动中途失败会回退，进程被强制终止或同步程序同时改动文件时，文件可能分布在原桌面和整理文件夹，需要手动核对。隔离目录测试没有触碰用户桌面；资源管理器定位只验证左半屏几何与调用路径，未验证实际 Explorer 窗口。使用 SetWindowPos 调整窗口，非 Windows Snap 分组。
- **文件副本与引用**：单个文件不超过 5 MiB 时复制到 `Data/Capsules`，更大文件和文件夹保存原路径。原文件移动、断开外置盘或网络共享不可用时，引用条目仍会留在配置中，但打开会提示恢复路径。升级时，旧版现存的小文件引用会在首帧显示后逐项迁移；已丢失、不可读取的源文件仍保留为引用。复制发生在 UI 后台优先级的定时回调中，不等于完全异步 I/O，大量旧条目迁移时可能偶有短暂停顿。移动便携目录应带上整个 `Data`。
- **自定义图标**：图标保存到 `Data/Icons`；请在升级或搬迁时保留整个 `Data`。手动修改或损坏该目录中的图片时会显示默认胶囊图。
- **任务栏外观**：依赖 ExplorerTAP 与 Windows Explorer 的相应接口。Windows 更新或其他任务栏美化工具可能影响效果。
- **轻量化**：目前披露的是文件体积，没有跨设备的 CPU、内存或启动速度基准数据。
- **发布文件**：当前 EXE 未使用代码签名证书。
