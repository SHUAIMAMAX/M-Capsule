# M-Capsule v1.2.0 · Isolated pre-release check

Status: **local candidate; nothing pushed to GitHub and no Release created.**

The offline build passed. Eight suites passed **333 isolated checks**: core configuration/language 96, grid/icon sizing 61, portable data 28, startup 15, glass 19, file handling 76, icon/vector artwork 16, and Ultimate Organizing Mode 22. Another **42 portable integration checks** passed. Fixtures used separate directories, synthetic wallpaper, and test shortcuts.

The audit fixed stale copies on reimport, temporary names that could exceed deep Windows paths, and reimport of a legacy large-file reference. Checks cover small/medium/large sizing, vector artwork, repeat organizing, and damaged old startup entries. Portable integration checks created test WPF windows. The production app was not started; real desktop icons, Explorer, taskbar, and Startup registration were not modified.

**User validation is still needed** for live Windows Shell icon-size reading, Ctrl+wheel appearance, DPI and multi-monitor display, Explorer drag/drop feedback, desktop layering, and sign-in timing. Large-file copying runs on the UI thread and may briefly block it; sufficient disk space is required. Windows 10 and ARM64 are not systematically verified, and the EXE is unsigned.

Upgrading from v1.1.0 or earlier requires the complete ZIP in the original portable folder while preserving `Data`. The old EXE alone cannot be replaced because its filename changed.
